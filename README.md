# MicroVoxTTS

Легковесный, автономный и невероятно быстрый REST API сервис для синтеза речи (Text-to-Speech), оптимизированный для работы на обычных VPS без видеокарт (GPU). В основе лежит нейросетевой движок **Piper TTS**.

## Особенности
* **Локальная работа**: Не требует интернета для синтеза.
* **Быстродействие**: Генерирует звук быстрее реального времени на обычных CPU.
* **Качество**: Использует современные нейросетевые голоса (ONNX модели).
* **Безопасность**: Защита эндпоинтов с помощью API ключа (токен авторизации).
* **Контроль нагрузки**: Защита сервера от "падения" при резких всплесках запросов (встроенная очередь-семафор).
* **Готово к Docker**: Деплой одной командой через `docker-compose`.

## Доступные языки
* `ru` — Русский (мужской голос, Дмитрий)
* `en` — Английский (женский голос, Лессак)
* `pl` — Польский (женский голос, Гося)

Модели автоматически скачиваются с HuggingFace при первом запуске и сохраняются в папку `models`.

## 🚀 Установка и запуск

1. Склонируйте или скопируйте файлы на ваш VPS.
2. Создайте файл окружения `.env` из примера:
   ```bash
   cp .env.example .env
   ```
3. Откройте `.env` и задайте ваш надежный пароль в переменную `API_KEY`. Там же можно настроить `MAX_CONCURRENT_REQUESTS` в зависимости от количества ядер на сервере (по умолчанию 2).
4. Запустите проект через Docker:
   ```bash
   docker-compose up -d --build
   ```

*(При первом запуске и первом запросе потребуется минута на загрузку моделей, последующие запросы и перезагрузки сервера будут происходить моментально).*

## 🎧 Использование API

### Проверка работоспособности
**GET `/`**
Возвращает список доступных языков и статус сервера.

### Генерация речи
**POST `/api/v1/tts`**
Основной метод генерации аудио.

**Обязательные заголовки:**
* `X-API-Key: ваш_секретный_ключ`
* `Content-Type: application/json`

**Пример запроса через cURL:**
```bash
curl -X POST "http://IP_ВАШЕГО_СЕРВЕРА:8000/api/v1/tts" \
     -H "Content-Type: application/json" \
     -H "X-API-Key: your-secret-api-key" \
     -d '{"text": "Привет! Как твои дела?", "lang": "ru"}' \
     --output speech.wav
```

В ответ вы получите бинарный файл `speech.wav`.

## Документация API (Swagger UI)
Когда сервер запущен, перейдите в браузере по адресу:
`http://IP_ВАШЕГО_СЕРВЕРА:8000/docs`

Там вы найдете визуальный интерфейс для тестирования запросов (не забудьте нажать на кнопку "Authorize" в правом верхнем углу, чтобы ввести ваш `API_KEY`).
